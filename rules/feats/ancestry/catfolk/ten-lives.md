# Overview

- **Level**: 17
- **Category**: Ancestry (catfolk)
- **Action**: Passive
- **Prerequisites**: Evade Doom
- **Traits**: catfolk

## Description

When your character would die, you can attempt a flat check (DC 17). On a success, you're instead reduced to 0 HP and a Dying value 1 less than what would normally kill you (typically dying 3). This doesn't change the result for any other creature affected.
