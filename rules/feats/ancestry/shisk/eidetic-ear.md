# Overview

- **Level**: 1
- **Category**: Ancestry (shisk)
- **Action**: Passive
- **Traits**: shisk

## Description

You have an amazing memory for sound. You gain the Assurance (Performance) feat. With a successful flat check (DC 8), you can accurately recall a sound or a snippet of conversation you heard within the last week. You are memorizing by rote rather than content, and can't use this to cram facts, so this doesn't grant you any extra ability to Recall Knowledge.
