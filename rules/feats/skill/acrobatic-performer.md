## Description

You're an incredible acrobat, evoking wonder and enrapturing audiences with your prowess. You can roll an [[/act perform skill=acrobatics variant=dance]]{Acrobatics} check instead of a Performance check when using the Perform action. If you are trained in both Acrobatics and Performance, you gain a +1 circumstances bonus on Acrobatics checks made to Perform.
