# Overview

- **Level**: 4
- **Category**: Class (kineticist)
- **Action**: 3 actions
- **Traits**: composite, impulse, kineticist, metal, primal, water

## Description

You conjure a red raincloud in a 10-foot burst within 60 feet, which pours rust-colored rain directly below it. Any creature in the rain with the metal trait, that is made of metal, or is wearing metal armor is covered in corrosive build-up. Any such creature is Clumsy 1 as long as it remains in the area. If such a creature is in the rain at the start of its turn, it takes (floor((actor level -4)/2)+3)d6 untyped]|options:area-damage damage with a fortitude save save against your class DC, plus 1d6 persistent untyped]|options:area-damage damage if it fails. Damage from this impulse ignores Hardness. The cloud lasts 1 minute but ends if you use the impulse again.

**Level (+2)** The initial damage increases by 1d6.
