# Overview

- **Level**: 8
- **Category**: Class (commander)
- **Action**: Passive
- **Special**: Can be taken up to 2 times.
- **Traits**: commander

## Description

You know that a broad knowledge base is critical for a competent commander. You become trained in two skills you are not already trained in, become an expert in one skill you are currently trained in, learn one common language you do not already know, and gain any one general feat that you meet the prerequisites for.

---

**Special** You can take this feat twice, gaining its benefits each time.
