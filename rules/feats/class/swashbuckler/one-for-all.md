# Overview

- **Level**: 1
- **Category**: Class (swashbuckler)
- **Action**: 1 action
- **Prerequisites**: trained in Diplomacy
- **Traits**: auditory, concentrate, emotion, linguistic, mental, swashbuckler

## Description

With precisely the right words of encouragement, you bolster an ally's efforts. Designate an ally within 30 feet; this action counts as sufficient preparation to Aid that ally. When you use the Aid reaction to help that ally, you can roll diplomacy save in place of the usual check and the action gains the bravado trait
