# Overview

- **Level**: 2
- **Category**: Class (bard)
- **Action**: 1 action
- **Prerequisites**: zoophonia muse
- **Traits**: auditory, bard, emotion, fear, mental

## Description

You can convey the subtle menace of a low growl or predatory rumble. Attempt a nature save or performance save check, and compare it to the Will DC of each enemy adjacent to you. If you have an animal minion, such as an animal companion or summoned animal, you can also compare it to each enemy adjacent to them. For each creature that you succeed at, it's Frightened 1 (or Frightened 2 if it's an animal). Regardless of the result, each target is temporarily immune to your Bestial Snarling for 10 minutes.
